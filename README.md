# IEUK 2026
## Sector Skills Project - Engineering

AeroGrid Health Check identifies anomalies in turbine operation, allowing engineers to perform urgent maintenance on failing machines.

To run, enter the following commands in a terminal:

```bash
git clone https://github.com/stya-xo/ieuk-26-engineering
cd ieuk-26-engineering
docker build -t aerogrid-health-check .
docker run aerogrid-health-check
```
